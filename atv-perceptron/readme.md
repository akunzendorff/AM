# Classificador de Sobrevivência Titanic - Perceptron Manual

Implementação manual de um Perceptron para a disciplina de Aprendizado de Máquina (Fatec Registro).

## Dataset
Baseado no desafio clássico do Kaggle: [Titanic Dataset](https://www.kaggle.com/c/titanic).

## Como rodar
1. Execute o notebook em `notebooks/notebook.ipynb` para ver a análise gráfica.
2. Ou execute `python main.py` para um teste rápido via terminal.
